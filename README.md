# 五个错凭证（分层设计）

一份用于演示「分层复核」的最小仓库：五个故意做错的凭证，每层一个。

## 目录

```
错凭证/
  01-数据层-借贷不平.json
  02-计量层-折旧算错.json
  03-准则层-反向冲红.json
  04-勾稽层-三流断.json
  05-定性层-未定性.json
复核结果.md      五个错各自被哪一层抓住（实测）
check_self.py    自含复核脚本（只用标准库，可在此仓直接跑）
```

## 为什么分五层

一处错只说明「某个检查有用」；五层各错一处，才能说明**每层的边界在哪**：
某层的错只该被该层抓住，若被上层抓住，往往意味着下层漏了。

```
① 数据层   借贷是否相等
② 计量层   算式对不对（折旧、递推、摊余成本）
③ 准则层   允许怎么做（冲红、追溯、列报）
④ 勾稽层   流与流对不对得上（票、货、款、往来）
⑤ 定性层   人说了算（交易实质、异常判断）
```

## 怎么跑

```bash
python check_self.py
```

输出每个错凭证的复核结论；5/5 抓住时退出码为 0。

## 一个刻意的限制

本仓**不含**任何完整会计引擎，只放错凭证与最小复核逻辑。
真实复核在另一个仓里做（那套带准则实现与自检），这里只证明：

> **同一份错数据，交给分层复核，能被对应层指出来；而且能说清是哪一层的责任。**
